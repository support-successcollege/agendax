  Agendax — מדריך חיבור רשתות חברתיות לפרסום אוטומטי
  (פאנל ניהול ← טאב "רשתות חברתיות")
════════════════════════════════════════════════════════════════════

עיקרון: לכל פלטפורמה מקימים "אפליקציה" חד-פעמית בפורטל המפתחים שלה,
מפיקים טוקן גישה, ומדביקים בפאנל. אחרי זה — מתג "פעיל" + מתג "אוטומטי"
והמערכת מפרסמת לבד.

חשוב: הטוקנים הם סודות. לא לשלוח אותם לאף אחד, לא לשמור בקבצים גלויים.
מדביקים ישירות בפאנל בלבד.

────────────────────────────────────────────────────────────────────
1) פייסבוק — הכי פשוט, תתחיל ממנו
────────────────────────────────────────────────────────────────────
דרישה מקדימה: עמוד פייסבוק (Page) של Agendax, שאתה מנהל שלו.

שלב א — יצירת אפליקציה:
  1. היכנס ל: https://developers.facebook.com
  2. My Apps ← Create App ← סוג "Business" ← תן שם (Agendax Publisher)
  3. בתוך האפליקציה: Add Product ← הוסף "Facebook Login for Business"

שלב ב — הפקת טוקן עמוד ארוך-טווח:
  1. פתח את: https://developers.facebook.com/tools/explorer
  2. למעלה בחר את האפליקציה שיצרת
  3. User or Page ← בחר "Get Page Access Token" ← בחר את עמוד Agendax
  4. בהרשאות (Permissions) ודא שמסומנות:
       pages_manage_posts, pages_read_engagement
  5. לחץ Generate Access Token ← אשר בחלון של פייסבוק
  6. הטוקן שקיבלת הוא קצר-טווח. כדי להאריך אותו:
     פתח את: https://developers.facebook.com/tools/debug/accesstoken
     הדבק את הטוקן ← לחץ "Extend Access Token" למטה
     (טוקן עמוד מוארך בדרך כלל לא פג — "Never Expires")

שלב ג — Page ID:
  בעמוד הפייסבוק ← About / אודות ← Page ID
  (או ב-Graph Explorer: שאילתה me?fields=id עם טוקן העמוד)

בפאנל:
  Page ID           = המספר מהשלב ג
  Page Access Token = הטוקן המוארך משלב ב

────────────────────────────────────────────────────────────────────
2) אינסטגרם — נשען על החיבור של פייסבוק
────────────────────────────────────────────────────────────────────
דרישה מקדימה: חשבון האינסטגרם agendax.co.il חייב להיות
חשבון Professional (Business) ומקושר לעמוד הפייסבוק:
  אפליקציית אינסטגרם ← הגדרות ← Account type and tools ←
  Switch to professional account ← Business ← קשר לעמוד הפייסבוק של Agendax.

שלב א — IG User ID:
  1. פתח את: https://developers.facebook.com/tools/explorer
  2. עם טוקן העמוד של פייסבוק (מסעיף 1), הרץ שאילתה:
       me?fields=instagram_business_account
  3. המספר שחוזר תחת instagram_business_account.id — זה ה-IG User ID

שלב ב — הרשאות:
  ב-Graph Explorer ודא שהטוקן כולל גם:
       instagram_basic, instagram_content_publish
  (אם לא — הוסף אותן ו-Generate Token מחדש, והארך שוב)

בפאנל:
  IG Business User ID = המספר משלב א
  Access Token        = אותו טוקן עמוד של פייסבוק

הערה: פרסום לאינסטגרם דורש תמונה — המערכת שולחת אוטומטית את תמונת
הכתבה. אין לינקים בפוסטים של אינסטגרם (מגבלה שלהם) — הפוסט מפנה
"לינק בביו", אז שים את agendax.co.il בביו של החשבון.

────────────────────────────────────────────────────────────────────
3) X (טוויטר)
────────────────────────────────────────────────────────────────────
שלב א — אפליקציה:
  1. היכנס ל: https://developer.x.com (התחבר עם חשבון @agendaxcoil)
  2. הירשם ל-Free tier אם עוד לא (מספיק לפרסום — עד 500 פוסטים בחודש)
  3. צור Project + App

שלב ב — הגדרת הרשאות:
  1. בתוך האפליקציה ← Settings ← User authentication settings ← Set up
  2. App permissions: Read and write
  3. Type of App: Web App
  4. Callback URI: https://agendax.co.il  (חובה למלא משהו)
  5. Website URL: https://agendax.co.il
  6. שמור

שלב ג — ארבעת המפתחות (OAuth 1.0a — לא פגים לעולם):
  1. Keys and tokens:
       Consumer Keys ← API Key and Secret ← העתק את שניהם
  2. באותו עמוד: Authentication Tokens ←
       Access Token and Secret ← Generate (או Regenerate) ← העתק את שניהם
  3. חשוב: ה-Access Token חייב להיות מופק *אחרי* שהגדרת
     App permissions = Read and Write (שלב ב). אם הופק לפני —
     לחץ Regenerate ותעתיק את החדשים.

בפאנל (4 שדות):
  API Key             = Consumer API Key
  API Key Secret      = Consumer API Key Secret
  Access Token        = Access Token
  Access Token Secret = Access Token Secret

אזהרה: לא להשתמש ב-"Bearer Token" שמופיע באותו עמוד — הוא טוקן
אפליקציה לקריאה בלבד, ופרסום איתו נדחה. רק ארבעת המפתחות למעלה.

────────────────────────────────────────────────────────────────────
4) לינקדאין — הכי בירוקרטית, השאר לסוף
────────────────────────────────────────────────────────────────────
שלב א — אפליקציה:
  1. היכנס ל: https://developer.linkedin.com ← Create app
  2. שם: Agendax Publisher, קשר לעמוד לינקדאין (או לפרופיל)
  3. Products ← בקש גישה ל: "Share on LinkedIn" ו-"Sign In with LinkedIn
     using OpenID Connect" (מאושרים אוטומטית בדרך כלל)

שלב ב — טוקן:
  1. באפליקציה ← Auth ← OAuth 2.0 tools (בצד ימין יש Token Generator)
  2. בחר scopes: w_member_social, openid, profile
  3. Request access token ← אשר ← העתק את הטוקן
  (תוקף: 60 יום. כשפג — מפיקים חדש באותו כלי, 2 דקות.)

שלב ג — Author URN:
  לפרופיל אישי: הרץ ב-OAuth tools את השאילתה userinfo, קח את השדה
  "sub" — ה-URN הוא: urn:li:person:<הערך של sub>
  לעמוד חברה (דורש אישור Community Management API — תהליך ארוך):
  urn:li:organization:<מספר העמוד>
  בשלב זה: השתמש בפרופיל האישי.

בפאנל:
  Author URN   = urn:li:person:XXXX
  Access Token = הטוקן משלב ב

────────────────────────────────────────────────────────────────────
5) הפעלה בפאנל
────────────────────────────────────────────────────────────────────
1. פאנל ניהול ← טאב "רשתות חברתיות"
2. בכל כרטיס: הדבק את השדות ← "שמור" ← הדלק מתג "פעיל"
3. בדיקה: בחלק "פרסום ידני" בחר כתבה + הפלטפורמה ← "פרסם עכשיו"
   ← בדוק שהפוסט עלה ברשת ← ביומן הפרסומים תראה ✓ ירוק
4. כשהבדיקה עברה: הדלק מתג "אוטומטי" — מעכשיו כל כתבה שמתפרסמת
   באתר תפורסם לבד גם ברשת (בדיקה כל 20 דקות)

────────────────────────────────────────────────────────────────────
6) תקלות נפוצות
────────────────────────────────────────────────────────────────────
- שגיאה ביומן עם "expired" / "invalid token" ← הטוקן פג. הפק חדש
  והדבק בפאנל. (X: שעתיים. לינקדאין: 60 יום. פייסבוק מוארך: כמעט לעולם.)
- אינסטגרם: "media not found" / שגיאת תמונה ← תמונת הכתבה לא נגישה
  או לא בפורמט נתמך (חייב JPEG). רוב תמונות המערכת תקינות.
- פייסבוק: "permissions error" ← חסרה הרשאת pages_manage_posts בטוקן.
  הפק טוקן מחדש עם ההרשאה.
- כלום לא קורה באוטומטי ← ודא שמתג "אוטומטי" דולק ושהכתבה פורסמה
  ב-12 השעות האחרונות (הסריקה מכסה רק כתבות טריות).

בהצלחה! כל שגיאה שלא ברורה — העתק את הטקסט מהיומן ושלח לי.
