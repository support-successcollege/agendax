# עורך Agendax

עובד עריכה לטיוטות שהסוכנים האוטומטיים של Agendax מייצרים (`ingest-worker`,
`generate-article`). קורא טיוטה, מנקה אותה, מתקן עברית, מודד אותה מול
הצ'ק-ליסט — ומעדכן את הטיוטה בחזרה ב-Supabase. **לעולם לא מפרסם**: `is_draft`
נשאר `true` תמיד.

## חלוקת עבודה

| שלב | מי מבצע | למה |
|---|---|---|
| מקפים, מקורות, פרסומות, טיפוגרפיה | `scripts/clean_draft.py` | דטרמיניסטי, אפס יצירתיות, אפס סיכון |
| איות, דקדוק, ניסוח, כותרות ביניים, דיסקליימר | Claude | דורש הבנת הקשר |
| כתיבה ל-DB | `scripts/agendax_db.py` או Supabase MCP | — |

הסקריפט רץ **תמיד ראשון**. אל תתקן מקפים או תמחק מקורות ידנית — זה תפקידו.

## תהליך

### 1. שליפת הטיוטות

אם מחובר קונקטור **Supabase** — השתמש בו:

```sql
select id, title, excerpt, content, category, created_at
from articles
where is_draft = true
order by created_at desc
limit 20;
```

אחרת דרך REST (דורש `SUPABASE_URL` ו-`SUPABASE_SERVICE_ROLE_KEY` בסביבה):

```bash
python3 scripts/agendax_db.py list --limit 20 --since 2026-08-18 > drafts.json
```

ברירת מחדל כשלא נאמר אחרת: כל הטיוטות מ-48 השעות האחרונות.
פרויקט Supabase: `kjazrljlfreczicstymr`. טבלה: `public.articles`.
`content` הוא HTML עם מחלקות Tailwind — **אסור לשנות את המחלקות או את מבנה התגיות.**

### 2. ניקוי מכני

```bash
python3 scripts/clean_draft.py --in drafts.json --out clean.json
```

מה הוא מטפל בו (הפירוט המלא ב-`references/cleaning-rules.md`):

- **מקפים** — `—` `–` `―` `−` הופכים ל-`-`. עם רווחים מסביב → ` - `.
- **מקורות** — כותרת "מקורות"/"קישורים"/"לקריאה נוספת" והבלוק שאחריה, פסקאות
  "מקור: ...", URL חשוף, וקישורים חיצוניים (הטקסט נשאר, התג יורד).
  ייחוס בגוף המשפט ("על פי הדיווח ב-TechCrunch") **נשאר** — זו דרישת E-E-A-T.
- **פרסומות** — בלוקים עם "בחסות"/"תוכן ממומן"/"Sponsored", פסקאות CTA
  ("לחצו כאן", "הירשמו עכשיו"), `adsbygoogle`, iframe, קישורי אפיליאייט.
- **טיפוגרפיה** — מרכאות מסולסלות, `…`, רווחים כפולים, רווח לפני פיסוק,
  `!!!`, תווי RTL נסתרים.

פסקת דיסקליימר לעולם לא נמחקת, גם אם היא מכילה "תוכן שיווקי".

דגלים: `--keep-links` (להשאיר קישורים חיצוניים), `--keep-ads` (רק לדווח),
`--report-only` (בלי להחזיר תוכן).

### 3. מעבר עריכה של Claude

קרא את `content` שיצא מהסקריפט ותקן **בעדינות**:

- שגיאות כתיב ואיות, כתיב מלא/חסר לא עקבי, יידוע כפול ("ה-ה"), התאמת מין ומספר.
- אותיות שימוש לפני מילים לועזיות: `ה-AI`, `ב-Nvidia`, `מ-2025` (עם מקף).
- מספרים ואחוזים: ספרות, לא מילים. פסיק כמפריד אלפים.
- ראשי תיבות: גרשיים כפולים לפני האות האחרונה — צה"ל, ארה"ב.
- מונח לועזי בהופעה ראשונה: עברית + הלועזי בסוגריים — מודל שפה גדול (LLM).
- כותרת: בלי קליקבייט, בלי סופרלטיבים ("מדהים", "חסר תקדים") — עובדה במקומם.

**מה אסור:** לשכתב פסקאות שלמות, להוסיף עובדות, מספרים, ציטוטים או שמות שלא
היו בטיוטה, או לשנות את משמעות הכתבה. אם עובדה נראית שגויה — לדווח, לא לתקן.
**קישורים פנימיים נשארים:** `<a href="/article/...">` בגוף הטקסט ופסקת
"קראו גם:" בסוף הכתבה הם חלק מהמערכת (קישור פנימי אוטומטי מ-`ingest-worker`).
לא מפרקים אותם, לא מוחקים את הפסקה, ולא משנים את ה-href.

### 4. בקרת איכות

עבור על `references/quality-checklist.md` וסמן לכל כתבה ✅ / ⚠️ / ❌ בשישה
קריטריונים: מקורות, ערך מקורי, E-E-A-T, מבנה וקריאות, אמיתות הכותרת, דיסקליימר.

אם חסר דיסקליימר — הוסף את התבנית המתאימה מ-`references/disclaimers.md`
כפסקה אחרונה, באותו מבנה HTML של שאר הפסקאות:

```html
<p class="text-foreground/90 leading-relaxed mb-4">...</p>
```

בחירת תבנית: שווקים/מניות/קריפטו → א'. תוכן בשיתוף מותג → ב'. כל השאר → ג'.

### 5. כתיבה חזרה

שמור גיבוי של המקור לפני עדכון (`drafts.json` הוא הגיבוי — אל תמחק אותו).

```bash
python3 scripts/agendax_db.py update --file clean.json
```

או דרך ה-MCP: `update articles set title=…, excerpt=…, content=… where id=…`.

מעדכנים רק `title`, `excerpt`, `content`. **לא** נוגעים ב-`is_draft`,
`published_at`, `slug`, `image_url`, `category`.

### 6. דוח

טבלה בעברית, שורה לכל כתבה:

| כותרת | מקפים | מקורות | פרסומות | תיקוני לשון | צ'ק-ליסט | הערות |
|---|---|---|---|---|---|---|

ואחריה: מה נמחק בפועל (טקסט מקוצר של כל בלוק שהוסר) ואילו אזהרות נשארו פתוחות
לטיפול שלך — עובדה חשודה, כותרת קליקבייטית, כתבה קצרה מדי.

## כללי בטיחות

1. `is_draft` נשאר `true`. הסקיל לא מפרסם, לא מתזמן ולא מוחק שורות.
2. כתבות שכבר פורסמו (`is_draft = false`) לא נגעות בהן אלא אם התבקש במפורש.
3. הניקוי אידמפוטנטי — הרצה חוזרת על טיוטה נקייה מחזירה 0 שינויים.
4. `SUPABASE_SERVICE_ROLE_KEY` לא נכתב לקובץ, לא ללוג ולא ל-git.
5. אם הוסרו יותר מ-40% מהתוכן — עצור, אל תעדכן, ודווח. זה סימן לזיהוי שגוי.
