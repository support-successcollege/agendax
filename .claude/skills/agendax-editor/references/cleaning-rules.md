# חוקי הניקוי המכני

מה `scripts/clean_draft.py` עושה, בדיוק. כל שינוי נרשם ביומן `changes`
עם `type`, `reason` וטקסט מקוצר, כדי שכל מחיקה תהיה ניתנת לביקורת.

## 1. מקפים

| תו | שם | הופך ל- |
|---|---|---|
| `—` | em dash | `-` |
| `–` | en dash | `-` |
| `―` `‒` | horizontal bar / figure dash | `-` |
| `−` | minus sign | `-` |
| `⸺` `⸻` `﹘` `﹣` `－` | וריאנטים | `-` |

הכלל: מקף עם רווח לפחות מצד אחד → ` - ` (רווח-מקף-רווח). מקף צמוד בתוך
מילה או צירוף (`ה-AI`, `Cloud-Native`) → `-` בלי רווחים.

## 2. טיפוגרפיה

- `“ ” „ « »` → `"` ; `‘ ’ ‚` → `'`
- `…` → `...` ; `....` ואילך → `...`
- `!!!` → `!` ; `???` → `?`
- רווח לפני `, . ; : ! ?` — נמחק. חוסר רווח אחרי — מתווסף (רק בין אותיות).
- רווחים כפולים → רווח יחיד. רווח אחרי `(` ולפני `)` → נמחק.
- תווי כיווניות נסתרים (LRM, RLM, LRE‑PDI, ZWSP, BOM) → נמחקים.
- NBSP ורווחים צרים → רווח רגיל.

## 3. מקורות

נמחק:

1. **בלוק מקורות** — כותרת (h1‑h6) שכולה אחת מ: מקורות / מקור / מקורות נוספים /
   קישורים / קישורים רלוונטיים / לקריאה נוספת / קרדיט / קרדיטים / הפניות /
   לינקים / Sources / References / Further reading — והכותרת עצמה, וכל האחים
   שאחריה עד הכותרת הבאה באותה רמה או גבוהה ממנה.
2. **שורת מקור** — פסקה שמתחילה ב-`מקור:` `מקורות:` `קרדיט:` `צילום:` `תמונה:`
   `Source:` `Credit:` `Photo:` `via:` ואורכה מתחת ל-300 תווים.
3. **URL חשוף** בתוך טקסט.
4. **קישורים חיצוניים** — התג `<a>` מפורק, טקסט העוגן נשאר במקומו.
   קישורים פנימיים (`agendax.co.il`, `/`, `#`) נשארים — אלא אם יש בהם
   פרמטרי מעקב.

**לא נמחק:** ייחוס בגוף המשפט — "על פי הדיווח ב-TechCrunch", "כך מדווח
The Verge", ציטוט מיוחס. זו דרישת Authoritativeness ב-E-E-A-T, ומחיקה שלה
הופכת את הכתבה לפחות אמינה, לא ליותר.

## 4. פרסומות

נמחק בלוק שלם (פסקה / div / רשימה / blockquote) אם:

- הוא מכיל סימן חסות ואורכו מתחת ל-600 תווים:
  תוכן שיווקי, כתבה ממומנת, פוסט ממומן, תוכן ממומן, בחסות, בשיתוף עם,
  בשיתוף פעולה עם, מודעה, פרסומת, פרסום:, ממומן, Sponsored, Advertisement,
  Advertorial, Promoted content, Paid partnership, Affiliate.
- הוא **קריאה לפעולה מובהקת** ואורכו מתחת ל-220 תווים:
  לחצו/לחץ/לחצי כאן, הירשמו/הרשמו/הצטרפו עכשיו, להרשמה לחצו, לפרטים נוספים
  לחצו, לפרטים והרשמה, קנו/הזמינו/רכשו עכשיו, נסו/התנסו בחינם, לרכישה לחצו,
  Buy now, Shop now, Sign up now, Subscribe now, Click here, Get started now.
- הוא **ניסוח מסחרי גבולי** — קוד קופון, קופון הנחה, הנחה בלעדית, מבצע בלעדי,
  במחיר מיוחד, Limited time offer, Learn more, Special offer, Exclusive deal —
  **ורק אם** אורכו מתחת ל-120 תווים או שיש בו קישור. פסקת חדשות אמיתית
  ("מבצע בלעדי שהשיקה החברה בשוק היפני העלה את המכירות ב-12%…") נשארת.
- הוא `<script>` `<style>` `<iframe>` `<noscript>`, או `<ins>` שמחלקתו מכילה
  ad / advert / banner / promo / sponsor / taboola / outbrain / dianomi.
- הוא קישור עם פרמטר מעקב או אפיליאייט: `utm_*`, `aff`, `affiliate`, `ref`,
  `referrer`, `partner`, `clickid`, `cid`, `fbclid`, `gclid`, `tag`, `campaign`.

### חריגים מוגנים

פסקה שנראית כמו **דיסקליימר** לא נמחקת לעולם, גם אם היא אומרת "תוכן שיווקי".
הזיהוי: אינו/אינה מהווה ייעוץ, האמור בכתבה, גילוי נאות, אינו מהווה המלצה,
באחריותו הבלעדית, למטרות מידע והעשרה, אינו מהווה תחליף, המערכת אינה אחראית,
דיסקליימר.

מיכל שמכיל בלוקים אחרים לא נמחק — רק עלים. כך פסקה פרסומית בתוך `<div>` לא
גוררת איתה חצי כתבה.

## 6. אזהרות שהסקריפט מרים (ולא מתקן)

- אין פסקת דיסקליימר.
- פחות מ-3 כותרות `<h2>`.
- אורך מתחת ל-450 מילים או מעל 950 (ההנחיה: 500‑850).

## מה הסקריפט לא עושה

לא מתקן שגיאות כתיב, לא משכתב, לא מוסיף כותרות ביניים, לא מוסיף דיסקליימר,
ולא שופט תוכן. כל אלה — מעבר העריכה של Claude.
